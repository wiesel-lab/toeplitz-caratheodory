# Data

All data is synthetic and generated by the experiment scripts with fixed
seeds. There is nothing to download.

- **Figure 1** uses the grid example of Section II-C: one source halfway
  between two grid frequencies, C = b v(w0) v(w0)^H + sigma^2 I with
  w0 = pi / K and b = 3 (`experiments/figure1.py`).
- **Figures 2 and 3** use a random ensemble of full-rank Toeplitz
  covariances, each built from P atoms plus the noise term 0.15 I. The
  frequencies of the atoms are uniform in [0, 2 pi), and their amplitudes are
  uniform in [0.5, A], where A is drawn uniformly from [2, 5] for each
  covariance (`src/data.py`).
- **Figure 3** also draws M proper complex Gaussian snapshots from each true
  covariance and forms their sample covariance (`src/data.py`).
